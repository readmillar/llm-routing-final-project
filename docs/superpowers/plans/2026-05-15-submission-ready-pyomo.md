# Submission-Ready Pyomo Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the project submittable for full credit by making the default report path a reliable A0-A3 Pyomo pipeline while keeping working extensions available behind explicit flags/configs.

**Architecture:** The default submission path is A0 weighted baseline, A1 single-shot portfolio MILP, A2 two-stage cascade MILP, and A3 robust scenario-weighted SAA cascade MILP. Optional extensions such as empirical recovery, A4 CVaR, large stress tests, provider/storage constraints, and three-stage cascades may remain in the repository if they are tested and disabled by default. `make run-final` generates only the artifacts used by the report; `make run-extensions` runs stretch experiments.

**Tech Stack:** Python 3.13, pandas, numpy, Pyomo, appsi_highs/highs with CBC/GLPK fallback, matplotlib, pytest, ruff, black, PyYAML.

---

## Scope Check

The assignment grades a 4-5 page report, a mathematically rigorous stochastic/robust/multistage optimization model, Pyomo implementation, visualizations, recommendations, and takeaways. A deterministic model is capped at 15/20, so the coding story should emphasize the stochastic two-stage cascade and robust SAA extension.

The core submission path should remain focused on A0-A3:

- A0 weighted assignment baseline.
- A1 single-shot portfolio MILP.
- A2 two-stage stochastic cascade MILP.
- A3 robust reliability-aware cascade MILP using scenario-weighted SAA and domain slacks.

This path uses `data/routerbench.csv`, preserves the incomplete observed prompt-model grid, keeps zero-cost rows, and writes report artifacts to `outputs_final/tables`, `outputs_final/figures`, and `outputs_final/solutions`.

Optional extensions may remain in the repository if all five are true:

- They do not run by default.
- They have tests.
- They do not break imports.
- They do not pollute `outputs_final` with confusing extension-only tables.
- They are clearly labeled optional in `README.md` and `docs/RUNBOOK.md`.

The final report should rely only on artifacts generated by the stable A0-A3 submission path unless an optional extension produces clean, auditable results and is explicitly discussed as an extension.

```python
import pyomo.environ as pyo

from .metrics import assignment_metrics
from .solver_utils import has_solution, no_solver_result, result_status, solve_model


def solve_a0(data, alpha, time_limit=300):
    """Solve A0 weighted assignment baseline as a Pyomo MILP over observed pairs."""
    policy = f"A0 alpha={alpha:g}"
    model = pyo.ConcreteModel()
    model.P = pyo.Set(initialize=data["P"])
    model.PM = pyo.Set(dimen=2, initialize=data["PM"])
    model.x = pyo.Var(model.PM, within=pyo.Binary)

    n_prompts = len(data["P"])

    def assignment_rule(mdl, prompt):
        return sum(mdl.x[prompt, model_name] for model_name in data["M_p"][prompt]) == 1

    model.assignment = pyo.Constraint(model.P, rule=assignment_rule)
    model.objective = pyo.Objective(
        expr=sum(
            (data["c"][(prompt, model_name)] - alpha * data["q"][(prompt, model_name)])
            * model.x[prompt, model_name]
            for prompt, model_name in data["PM"]
        )
        / n_prompts,
        sense=pyo.minimize,
    )

    solver_name, results, diagnostics = solve_model(model, time_limit=time_limit, policy=policy)
    if solver_name is None:
        return no_solver_result(policy, diagnostics)

    status = result_status(results)
    if not has_solution(status):
        return {
            "policy": policy,
            "alpha": alpha,
            "status": status,
            "solver": solver_name,
            "message": str(results.solver.termination_condition),
            "diagnostics": diagnostics,
        }

    assignment = {}
    for prompt in data["P"]:
        for model_name in data["M_p"][prompt]:
            value = pyo.value(model.x[prompt, model_name], exception=False)
            if value is not None and value > 0.5:
                assignment[prompt] = model_name
                break

    if set(assignment) != set(data["P"]):
        return {
            "policy": policy,
            "alpha": alpha,
            "status": status,
            "solver": solver_name,
            "message": "Solver stopped before loading a complete assignment",
            "diagnostics": diagnostics,
        }

    metrics = assignment_metrics(data, assignment, policy)
    metrics.update(
        {
            "alpha": alpha,
            "status": "feasible" if status == "feasible_time_limited" else status,
            "solver": solver_name,
            "diagnostics": diagnostics,
            "objective_value": sum(
                data["c"][(prompt, model_name)] - alpha * data["q"][(prompt, model_name)]
                for prompt, model_name in assignment.items()
            )
            / n_prompts,
        }
    )
    return metrics
```

def run_weighted_baselines(data, alphas=None, time_limit=300):
    """Return A0 summary rows and full assignment results for all alphas."""
    results = [
        solve_weighted_baseline(data, alpha, time_limit=time_limit)

    )
